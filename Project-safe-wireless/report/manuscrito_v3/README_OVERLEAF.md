# Compilar en Overleaf

1. En Overleaf, elige **New Project → Upload Project** y carga `safe_wireless_v3_overleaf.zip`.
2. El archivo principal es `main.tex`.
3. Compila con **pdfLaTeX**. El paquete conserva `Definitions/mdpi.cls`, las figuras y los recursos del formato MDPI.
4. Si Overleaf muestra un error, comparte el primer mensaje de error del registro junto con el PDF compilado; no borres las carpetas `Definitions` ni las imágenes.

El manuscrito está en inglés y mantiene el formato MDPI/Sensors de la versión anterior.

El PDF V3 compilado se guarda por separado en esta carpeta del repositorio; este ZIP contiene los fuentes para compilar, no el PDF final.
